Un game designer s'intéresse à la conception des règles et du contenu d'un jeu, et de l'impact que le gameplay aura sur les joueurs.

C'est un rôle bien spécifique, qu'on confond parfois avec d'autres dans un studio :

# Contraste avec d'autres rôles

Pour définir le pourtour du rôle de game designer, il peut être utile de voir ce qu'un game designer n'est pas.
## Game Designer vs. Direct•eur•rice Créati•f•ve

Un directeur créatif est responsable de la direction globale d'un projet/studio, et supervise l'ensemble des équipes (y compris les game designers) pour maintenir cette vision.

## Game Designer vs. Direct•eur•rice Artistique

Un directeur artistique supervise les équipes artistiques pour mettre en place l'esthétique du projet. Il est garant de la cohérence visuelle du projet.

## Game Designer vs. Programmeu•r•se

Les programmeurs implémentent les systèmes et les mécaniques de jeu selon les spécifications. Tout comme les artistes réalisent les éléments graphiques.

## Game Designer vs. Product•eur•rices

Le rôle de producteur est d'assurer un bon fonctionnement du studio, en conservant un regard sur les ressources disponibles (budget, temps, membres de l'équipe…).

# La réalité du terrain

Dans une petite structure (la plupart des studios indépendants) :

- Il existe un certain chevauchement entre certains rôles   
- Une même personne peut endosser plusieurs rôles simultanément
- Il est rare de trouver des personne strictement confinées au rôle de Game Designer

# Sous-spécialités

Le Game Design, en tant que discipline, est lui-même divisé en plusieurs sous-catégories, certaines qu'on retrouve dans la plupart des studios, d'autres qui sont plutôt réservées aux plus grandes structures.

- **Level Design** : Conception des environnements de jeux (du point de vue fonctionnel, pas esthétique, qui est le rôle des Environment Artists)
- **Narrative Design** : Discipline couvrant l'intégration d'éléments narratifs dans le gameplay. Différent de l'écriture à proprement parler.
- **Combat Design** : (peut se décliner comme Encounter Design ou autres termes similaires) Conception des situations de conflit expérimentées par les joueurs.
- **Quest Design** : Choix des étapes de résolutions et des temps forts des "quêtes". Terme qu'on retrouve souvent dans le domaine des jeux open world (ex: Assassin's Creed).

La liste ci-dessus n'est bien entendu pas exhaustive. Plus le studio est grand, plus les rôles peuvent se spécialiser.
