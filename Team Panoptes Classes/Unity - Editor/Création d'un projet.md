Chaque fois que vous voudrez créer un nouveau projet, vous allez aller dans la partie "projects" de Unity Hub.

![](unity_hub_projects.excalidraw.svg)
%%[🖋 Edit in Excalidraw](unity_hub_projects.excalidraw.md)%%

Cliquez ensuite sur "New project" à droite.

Vous allez ensuite devoir choisir une version de Unity (parmi celles installée sur votre machine) ainsi qu'un template pour votre projet.

Les trois premiers templates, sont ceux des versions classiques de projet Unity (c'est ceux qu'on va utilisez dans le plus part de nos cours), les autres sont dédiés à des tutoriaux ou des exemples d'implémentions de features.
![](template_choice.excalidraw.svg)
%%[🖋 Edit in Excalidraw](template_choice.excalidraw.md)%%

Ensuite, Choisissez une organisation. Vous pouvez en avoir plusieurs en fonction de vos besoins, par exemple si vous travaillez pour un studio, mais aussi sur des projets personnels.

Donnez aussi un nom à votre projet et indiquez à Unity l'emplacement qu'il va prendre sur votre machine.

Optionnellement vous pouvez choisir un "source control provider".
Si vous donnez les accès à Unity, il peut gérer la création de votre projet sur un server Git (GitLab ou GitHub) ou sur Unity Version Control.

![[project_location.png]]

Une fois que tout ça est rempli, il ne reste plus qu'à appuyer sur le bouton "+ Create project", qui se trouve en bas à droite de votre fenêtre.

Unity ouvrira votre projet automatiquement.
