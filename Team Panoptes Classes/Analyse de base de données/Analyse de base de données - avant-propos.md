## Objectif du cours

Ce cours à pour but de vous familiarisé avec l'univers des bases de données en générales et de vous faire comprendre leur utilités.

Il a aussi pour objectif de vous donner une méthodologie pour apprendre à créer des architectures de bases de données solides et efficaces. Une grande partie de l'efficacité d'un code qui interroge une base de données, passe par la manière dont sont structurées les données elles-mêmes.

## Petit disclaimer

L'analyse de base de données est un ensemble de méthode qui sont un peu des recettes de cuisine. Dans ce cours, je vous apporterai, en plus des "recettes", les trucs et astuces que j'ai appris avec les années. 

Je pourrais vous donner ma recette de tarte à la patate douce et vous expliquer tout les petits trucs pour qu'elle soit délicieuse et moelleuse, si vous ne tenter pas d'en faire (et d'en refaire), vous n'apprendrez pas à faire une délicieuse et moelle tarte à la patate douce.

Pour l'analyse de base de données, c'est pareil. Donc afin de vous faire pratiquer, ce cours contiendra beaucoup d'exercice. Faites-les, c'est important.
