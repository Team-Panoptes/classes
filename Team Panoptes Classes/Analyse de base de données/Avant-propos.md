## Objectif du cours

Ce cours à pour but de vous familiarisé avec l'univers des bases de données en générales et de vous faire comprendre leur utilités.

Il a aussi pour objectif de vous donner une méthodologie pour apprendre à créer des architectures de bases de données solides et efficaces. Une grande partie de l'efficacité d'un code qui interroge une base de données, passe par la manière dont sont structurées les données elles-mêmes.
## Exemples illustrés en Anglais 

Bien que le cours soit écrit en français, les exemples donnés dans le cours sont en anglais. La raison est simple, l'anglais est le langage de l'informatique et de la programmation, les bases de données n'y font pas exceptions.

## Mermaid

Les diagrammes réalisé pour ce cours sont *écrits* en [Mermaid](https://mermaid.js.org/intro/). Une partie du cours sera dédiées à l'apprentissage de ce *langage*. Ils pourrait s'avérer utiles pour vous, même en dehors du cadre de ce cours.
