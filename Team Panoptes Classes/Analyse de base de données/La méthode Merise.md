## Qu'est ce que la méthode Merise

Il s'agit d'une méthodologie de modélisation française qui a été conçue dans les années 70-80, principalement utilisée pour la conception de bases de données.  
[<font size=2>Source: wikipedia</font>](https://fr.wikipedia.org/wiki/Merise_(informatique))

Bien qu'elle soit ancienne, elle est toujours pertinente aujourd'hui et est largement utilisée dans le domaine informatique.

Cette méthode se repose sur la construction de plusieurs documents afin de modéliser la base de données la plus performante possible.

Les fameux documents sont: 
- Dictionnaire de données
- Modèle Conceptuel de Données ou MCD
- Modèle Logique de Données ou MLD
- Modèle Physique de Données ou MPD

Notre but en tant qu'informaticien·ne  est de livré un modèle physique des données car c'est la représentation de ce qui sera implémenté dans la base de données.
